# In het Engels gebruikt hij daarvoor de teksten van de S-57-catalogus van
# OpenCPN; dit bestand levert het Nederlands.
#
# Indeling:
#   [klassen]     objectsoort = Nederlandse naam
#   [opbouw]      objectsoort = kenmerken die, in deze volgorde, de naam
#                 aanvullen
#   [KENMERK]     waarde = Nederlandse betekenis (per S-57-kenmerk)
#
# Een eigen bestand met dezelfde naam (s57-nl.txt) in de Legend-map vult dit
# bestand aan of verbetert regels; de regels daarin gaan voor.
#
# Bronmarkering achter #:
#   [K1 Q20]    Kaart 1 / INT 1 (Vlaamse uitgave 2017, gelijk aan de
#               Nederlandse), met itemnummer
#   [BPR b7 ..] Binnenvaartpolitiereglement, bijlage 7 (verkeerstekens)
#   [BPR b8]    Binnenvaartpolitiereglement, bijlage 8 (markering vaarwater)
#   [IHM]       IHM-legenda ENC-kaarten Noordzee (Dienst der Hydrografie)

#
